# Changelog

All notable changes to StringTheory will be documented in this file.

## [0.5.0]
### Added
- Tab navigation for Scales, Chords, and Arpeggios.
- Active tab indicator using the application's accent color.
- Placeholder views for upcoming explorer modes.
- Persistent fretboard settings when switching between modes.

### Changed
- Relocated tuning and fret count controls below the fretboard.
- Standardized the mode-specific controls area to reduce layout movement.
- Improved the visual hierarchy of the Fretboard Explorer.

## [0.4.0]
### Added
- Core music theory engine.
- Categorized library of 49 scales.
- Algorithmic scale mode generation.
- Root note selection and highlighting.
- Full-neck and adjustable position visualization.

## [0.3.0]
### Added
- Ten guitar tuning presets.
- Adjustable fret count.
- Interactive fretboard controls.

## [0.2.0]
### Added
- Reusable SVG fretboard component.
- String labels and fret numbering.
- Single and double fret markers.
- Initial dark theme.

## [0.1.0]
### Added
- React, TypeScript, and Vite project initialization.
- Initial application structure.
- GitHub repository and version control.
